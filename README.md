# Конкурс прогнозов · ЧМ 2026 — дашборд

Живой дашборд портфельного прогноза на групповой этап ЧМ-2026.

- `index.html` — сам дашборд (открывается на GitHub Pages).
- `results.json` — результаты команд; обновляется автоматически.
- `update_results.py` — тянет результаты с football-data.org и пересчитывает `results.json`.
- `.github/workflows/update.yml` — робот GitHub Actions: запускает обновление каждые ~5 минут.

API-ключ хранится в секрете репозитория `FOOTBALL_DATA_TOKEN` и в сайт не попадает.

Ничего запускать на своём компьютере не нужно — всё работает в облаке.
